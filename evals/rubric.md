# Scoring rubric (0-4 per row)

| Criterion | 0 | 2 | 4 |
|---|---|---|---|
| Correctness | Tests fail | Core path passes | All tests plus edge cases |
| Tests | None | Happy path | Edge and failure cases, network mocked |
| Design | Tangled | Reasonable | Small, composable, documented |
| Source integrity | Uncited output | Some URLs | Every item carries source and date |
| Safety | Hardcoded secrets or unbounded requests | Timeouts | Timeouts, retries, no secrets |
